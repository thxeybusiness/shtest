# shtest

Application Next.js déployée sur Vercel.

- **Dépôt** : `thxeybusiness/shtest` (branche `main`)
- **Projet Vercel** : `shtest` (équipe `thxey`)

## Développement

```bash
npm install
npm run dev
```

L'application tourne sur http://localhost:3000.

## Déploiement

Une fois le dépôt connecté au projet Vercel (Vercel → Project `shtest` →
Settings → Git → Connect Git Repository) :

- push sur `main` → déploiement **production**
- push sur une autre branche → déploiement **preview**

## Stack

Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · TypeScript
